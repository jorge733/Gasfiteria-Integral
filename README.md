# Gasfitería Integral — Demo de rediseño

Propuesta de nuevo sitio web para **gasfiteriaintegral.cl**, preparada como demo para presentar al cliente.

> ⚠️ **Es una DEMO.** Teléfonos, correo, precios, cifras y opiniones son referenciales y deben reemplazarse por los datos reales antes de publicar.

## Qué incluye

- Diseño moderno, responsive (móvil primero) y rápido: HTML + CSS + JS, sin frameworks ni build.
- Llamados a la acción claros: botón de llamada, WhatsApp flotante y formulario que abre WhatsApp con el mensaje listo.
- Secciones: servicios con precios "desde", proceso de trabajo, por qué elegirnos, comunas de cobertura, opiniones, preguntas frecuentes y contacto.
- SEO básico (title, description, HTML semántico) y accesibilidad (contraste, foco, `prefers-reduced-motion`).

## Ver la demo

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

## Antes de publicar

1. Reemplazar `+56 9 0000 0000` / `56900000000` (en `index.html` y `WHATSAPP` en `script.js`) y el correo.
2. Ajustar servicios, precios, comunas y cifras.
3. Cambiar las opiniones de ejemplo por reseñas reales (p. ej. de Google).
4. Quitar la barra amarilla de DEMO y la etiqueta `<meta name="robots" content="noindex, nofollow">`.
5. Agregar fotos reales de trabajos y del equipo.
